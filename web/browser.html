1. Choose your moment

Highlight suggestions use audio energy, not AI judgement. Max clip length: 3 minutes.

2. Add captions optional

First use downloads a speech model from Hugging Face. It may take a few minutes. Check the transcript before exporting; model accuracy varies by language and audio.

Manual lines are spaced evenly; generated captions use speech timings. Changes to the selected time range clear existing captions.

No signup, API key or desktop installation. Local video files stay on your device. For YouTube/Twitch imports, the link is sent to the download server, which temporarily fetches the video and sends it to your browser.

The video engine downloads when you first process a file. Captions download an additional model only when requested.

Use a recent desktop Chrome or Edge for best results. Large files and long clips can exceed your browser's memory. Mobile performance varies.

Use videos you own or have permission to clip. Platforms may refuse downloads from hosting networks; if an import is refused, the site explains the failure. Live recording, social posting and the desktop app's AI ranking are not available here.
